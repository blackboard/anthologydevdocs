Working with the Link and Content Service

Published: November 26, 2026

Last Update: November 25, 2026

 

The Link and Content Service (LCS for short) is an LTI Advantage service from 1EdTech. It lets your tool find and manage the content it owns inside a Blackboard LMS course. Deep Linking 2.0 lets a user add your content to a course through a UI flow. LCS lets your tool work with that content afterwards, without anyone in the UI. Your tool can list its links, read one link, update it or create a new one.

LCS is a sibling of the Line Item service in the Assignments and Grades Service. AGS manages grade columns. LCS manages the LTI Resource Links (the course content items) that point to your tool.

CAVEAT

LCS only gives you access to the content items that belong to your tool. You cannot see or change course content created by other tools or by the instructor. This includes items that came from Deep Linking, items added manually from a Course Content placement, items imported from a Common Cartridge and items brought over by a course copy. Blackboard LMS decides which items your tool owns the same way it decides which tool to launch for a link.

What can you do with it?​

Some common scenarios where LCS helps your integration:

ScenarioHow LCS helps
"Already in course" indicatorBefore showing your Deep Linking content picker, list the items already in the course and flag them, so instructors don't add the same content twice.
Pointing links to new versionsWhen an instructor creates a new version of an activity in your tool, update the link's url and/or custom parameters so it launches the latest version, even after a course copy.
Reflecting availabilityRead the published state and availability dates of a link, so your tool can block access to a resource that is hidden in the course.
Date synchronizationPush availability and submission date changes made in your tool back to Blackboard LMS.
Title updatesWhen an activity is renamed in your tool, rename the link in the course too.
Link maintenanceBulk-update launch URLs (for example, after a domain change) without asking instructors or administrators to edit links by hand.
Orphan clean-upFind activities in your tool that no link in any course points to any more, and remove them.

Before you start​

LCS uses the same LTI 1.3 infrastructure as the other LTI Advantage services, so nothing new is needed on the Developer Portal side. Make sure that:

  1. Your tool is registered in the Developer Portal and deployed to the Blackboard LMS instance you are testing against.
  2. Your tool can complete an LTI launch and validate the id_token.
  3. Your tool can request a bearer token for the LTI subsystems.

The Link and Content Service claim​

When LCS is available, Blackboard LMS adds the following claim to every LTI launch from a course, whatever the message type (LtiResourceLinkRequest, LtiDeepLinkingRequest, etc.):

https://purl.imsglobal.org/spec/lti/claim/linkcontentservice
PropertyDescriptionType
versionVersions of the service supported by Blackboard LMS. Currently ["1.0.0"].Array[String]
scopesScopes your tool can request a token for in this context. These tell you which operations are allowed.Array[String]
typesContent item types supported in this context. ltiResourceLink is always included.Array[String]
contentitemsURL to list your tool's items in the current course, and to create new ones (if allowed).String
contentitemOnly on resource link launches. URL of the link being launched, used to read or update it.String

Launching from a course content item​

When the user launches an LTI link from the course, the claim includes the contentitem URL of that link:

"https://purl.imsglobal.org/spec/lti/claim/linkcontentservice": {
  "version": ["1.0.0"],
  "scopes": [
    "https://purl.imsglobal.org/spec/lti/scope/contentitem.read",
    "https://purl.imsglobal.org/spec/lti/scope/contentitem.update",
    "https://purl.imsglobal.org/spec/lti/scope/contentitem.create"
  ],
  "types": ["ltiResourceLink"],
  "contentitems": "https://learn.blackboard.com/learn/api/v1/lti/courses/_4_1/contentItems",
  "contentitem": "https://learn.blackboard.com/learn/api/v1/lti/courses/_4_1/contentItems/_3712_1"
}

Launching from other placements​

For launches that are not tied to a specific link, such as a Deep Linking request or a Course tool placement, the claim has no contentitem property. You can still list the items in the course with contentitems:

"https://purl.imsglobal.org/spec/lti/claim/linkcontentservice": {
  "version": ["1.0.0"],
  "scopes": [
    "https://purl.imsglobal.org/spec/lti/scope/contentitem.read"
  ],
  "types": ["ltiResourceLink"],
  "contentitems": "https://learn.blackboard.com/learn/api/v1/lti/courses/_4_1/contentItems"
}
Always check the scopes in the claim

Don't assume every operation is available. The scopes array in the claim lists what your tool can do in this context. Read access is always included. Update and create depend on what is allowed for your tool and the course. Only request the scopes that are listed in the claim.

Service access without LTI launch

As with AGS, you can cache the contentitems URL from a launch and use it later, for example from a background job, to call the service without a user present. Refresh your cache on later launches so you always have current URLs.

Scopes and allowed methods​

ScopeDescriptionAllowed HTTP method
https://purl.imsglobal.org/spec/lti/scope/contentitem.readList your tool's items, or read a single item.GET
https://purl.imsglobal.org/spec/lti/scope/contentitem.updateUpdate one of your tool's items.PUT
https://purl.imsglobal.org/spec/lti/scope/contentitem.createCreate a new item in the course.POST

Authenticating to the service and authorizing the requests​

LCS uses the same bearer token as AGS and Names and Roles. Follow Authenticating to the LTI Subsystems, and add the LCS scopes you need to the space-separated scope value of the token request. For example:

scope=https://purl.imsglobal.org/spec/lti/scope/contentitem.read https://purl.imsglobal.org/spec/lti/scope/contentitem.update https://purl.imsglobal.org/spec/lti-ags/scope/lineitem
One token, several services

If your tool uses LCS together with AGS (for example, to read the grade column linked to a content item), request all the scopes in a single token request.

Send the following headers on LCS requests. Note that LCS uses plain application/json, not the AGS-specific media types:

NameValue
Acceptapplication/json
Content-Typeapplication/json (only for PUT and POST requests)
AuthorizationBearer {access_token} received from the authentication request

Available endpoints​

Always use the URLs from the claim and from the id of each content item. Don't build them yourself.

EndpointDescriptionAvailable methods
contentitems URL (from claim)Lists all of your tool's items in the course. Also used to create a new item.GET, POST
contentitem URL / item idReads or updates a single content item.GET, PUT

The content item object​

Content items use the same format as the ltiResourceLink type in Deep Linking 2.0, with a few additions and differences:

FieldDescriptionValueExample
idFull URL of this content item. Use it to read or update the item. Read-only.String (URL){learn_domain}/learn/api/v1/lti/courses/_4_1/contentItems/_3712_1
typeContent type. Read-only.StringltiResourceLink
resourceLinkIdSame value sent as the resource link ID when this link is launched. Read-only.String_3712_1
titleTitle of the item as shown in the course.String"Chapter 12 quiz"
textDescription of the item.String"Quiz about chapter 12"
urlLaunch URL of the link. Can be blank if the link uses the tool's default target link URI.String (URL)https://lti.example.com/launch
customCustom parameters defined on this link only. Tool-level custom parameters are not included. Substitution variables are returned as is ($Variable).Object{ "quiz_id": "az-123" }
lineItemIdsAGS line item URLs linked to this item, if any. Replaces the Deep Linking lineItem property. Read-only.Array[String (URL)]["{learn_domain}/learn/api/v1/lti/courses/_4_1/lineItems/_40_1"]
publishedWhether the item is visible to students.Booleantrue
availableAvailability window, with startDateTime and/or endDateTime.Object (ISO dates){ "startDateTime": "2026-02-06T20:05:02Z" }

Grading lives in AGS

A content item never contains the grade column itself, only its URL in lineItemIds. To read or change the maximum score, label or due date of the grade column, use the Assignments and Grades Service with that URL. If there is a single linked column, its URL is the same as the lineitem value in the AGS claim of the launch.
